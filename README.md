# m5stack-joyC-ESPNow
M5StickC Plus and joyC sample. Send data used ESPNow.

## スティック

- 右：左右方向に操作
- 左：上下方向に操作

## 動作対象
"Kani"
  - 使用モーター
    - 前後2つの360度サーボで4足で横方向に歩行する。サーボ前後逆回転で旋回運動
    - Servo 360 Front
    - Servo 360 Back
  - スティック操作
    - 右：左右に倒して左右方向に歩行
    - 左：右スティックを操作中に上または下に入れると旋回運動
"Tako"
  - 使用モーター
    - 顏の上下方向を変えるサーボと、足を右または左回転させるサーボ
    - Servo 180 Head
    - Servo 360 Leg
  - スティック操作
    - 右：左右に倒して足サーボを左右方向に回転
    - 左：上または下に入れると顏を上下
"Car"
  - 使用モーター
    - 左右のタイヤを同じ方向に正逆転させるサーボ2つ（左右のタイヤは正負逆回転で同一方向）
    - Servo 360 L
    - Servo 360 R
  - スティック操作
    - 右：
      - 左スティックを上＋右スティックを右＝左モータ前進、右モータは停止
      - 左スティックを上＋右スティックを左＝右モータ前進、左モータは停止
      - 左スティックを下＋右スティックを右＝左モータ後退、右モータは停止
      - 左スティックを下＋右スティックを左＝右モータ後退、左モータは停止
    - 左：上または下に入れると両DCモータを使って前進／後退
"Buggy"
  - 使用モーター
    - 左右のタイヤを同じ方向に正逆転させるDCモータ2つ（左右のタイヤは正負逆回転で同一方向）
    - DC L
    - DC R
  - スティック操作
    - 右：
      - 左スティックを上＋右スティックを右＝左モータ前進、右モータは停止
      - 左スティックを上＋右スティックを左＝右モータ前進、左モータは停止
      - 左スティックを下＋右スティックを右＝左モータ後退、右モータは停止
      - 左スティックを下＋右スティックを左＝右モータ後退、左モータは停止
    - 左：上または下に入れると両DCモータを使って前進／後退
"Tank"
  - 使用モーター
    - 左右のタイヤを同じ方向に正逆転させるDCモータ2つ（左右のタイヤは正負逆回転で同一方向）
    - DC L
    - DC R
  - スティック操作
    - 右：左または右に入れると旋回運動（左スティック操作時より優先される）
    - 左：上または下に入れると両DCモータを使って前進／後退
